# dsh-voice-hotkey

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）的极简语音输入：**`Alt+V` 开录，静音自动停，说完按回车就发**，全程不碰鼠标。

它故意做得很小：录音、转写、写回草稿仍然是官方「语音输入」插件在做，本插件只负责替你去按它的按钮，并补上它没有的两件事 —— 热键和静音判停。

[English](README.md)

## 它做什么

| | |
|---|---|
| **热键** | `Alt+V` 轻按开始、再按停止。页面任意位置生效，不用先点输入框。 |
| **按住说话** | 按住 `Alt+V` 超过 0.5 秒说话，松手立刻停 —— 对讲机手感，不等静音。 |
| **静音自动停** | 检测到说话后，连续安静 N 秒（默认 2 秒）自动停。可设 1–5 秒，也可以整个关掉。 |
| **焦点** | 开录前先把光标放回输入框末尾，于是转写结果落在那里，`Enter` 直接发送。 |

## 前置条件

- **必须启用官方「语音输入」插件**（插件页里的「语音输入」）。本插件驱动的是它的按钮，少了它热键没有反应。
- 支持麦克风的桌面浏览器。音频在浏览器内录制、按官方插件原有路径发到 dsh 服务器，本插件不新增任何网络请求。

## 安装

```sh
dsh plugin --profile web add dsh-voice-hotkey
```

从本地目录装也可以：

```sh
dsh plugin --profile web add /path/to/dsh-voice-hotkey
```

然后刷新页面。热键不需要额外配置；可调项在 **插件 → 语音快捷键**。

## 设置

存在浏览器 `localStorage`，改完立即生效：

- **静音后自动停止** —— 关掉就是纯手动模式，自己再按一次 `Alt+V`。
- **静音多久算说完** —— 1 秒到 5 秒。

## 注意与边界

- 静音判定看音量包络，不看语义；说话中间停顿超过设定时长会被判为说完了。
- 判定阈值会自适应环境底噪；环境很吵时，用「按住说话、松手停」更稳。
- 不支持「边说边出字」—— 官方识别是整段返回的。
