# 语音快捷键

只做两件事，其余全部交给官方的语音输入插件（录音、转写、写回草稿都不重写）。

## 1. 全局热键

- **轻按 `Alt+V`**：开始录音；再轻按一次：停止并转写。
- **按住 `Alt+V` 不放**（超过 0.5 秒）说话，**松手立刻停止**并转写 —— 像对讲机，不用等静音判定。

热键在页面任意位置都生效，不需要先点输入框；插件开录前会先把光标放回输入框末尾，所以转写完按回车就能发送。

## 2. 静音自动停

开始录音后，插件自己开一路麦克风做能量分析：确认听到说话后，若连续静音达到设定时长（默认 2 秒），就替你点官方那个「停止并识别」。

阈值是自适应的（跟随环境底噪），因此：

- 按下热键后**先静半秒再开口**，底噪校准更准；
- 环境噪声很大（风扇、麦克风加强）时可能判不出静音，此时用「长按说话、松手停」更可靠。

## 3. 设置

**插件 → 语音快捷键** 的详情页里有配置区：

- 「静音后自动停止」：关掉就退回纯手动模式（必须自己再按一次 `Alt+V`）。
- 「静音多久算说完」：1–5 秒。

设置保存在浏览器 `localStorage`，改完立即生效，不需要重启。

## 边界

- 依赖官方 `dsh-experimental-client-ui-voice-input` 渲染的按钮；它没启用时热键不会有反应（控制台会有一次 `[voice-hotkey]` 警告）。
- 转写仍走官方链路（SenseVoice 本地模型），本插件不改变识别质量。
- 静音判定只看音量，不看语义；说话中间停顿超过设定时长会被判为说完了。
- 不支持「边说边出字」：官方的识别是一次性返回的。
