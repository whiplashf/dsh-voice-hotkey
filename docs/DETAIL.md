# 语音快捷键

补官方语音输入插件缺的三件事：可配置的语音热键、静音自动停、聚焦输入框。录音、转写、写回草稿都不重写。

## 1. 语音热键（默认 `Alt+V`，可改）

- **轻按**：开始录音；再轻按一次：停止并转写。
- **按住超过 0.5 秒**说话，**松手立刻停止**并转写 —— 对讲机手感，不用等静音判定。
- **录音中按一下空格**也能立刻停止并转写，等于替你点了「停止并识别」。只在录音（或正在启动的那几百毫秒）时拦截，其余时候空格照常打字；带 `Ctrl` / `Alt` / `Meta` 的空格不拦，输入法候选中的空格也不拦。

页面任意位置生效，不需要先点输入框。开录前会把光标放到输入框末尾（官方插件在这一刻记录插入位置）。

录制新组合键时必须带 `Ctrl` / `Alt` / `Meta` 之一，否则会抢走正常打字；与另一个热键撞车会被拒绝。

**可以整个关掉**：点键位进入录制，按 `Esc` 直接清成「未设置」（`Backspace` / `Delete` 同样有效）。设为「未设置」后该功能不注册任何监听。

只有按下带 `Ctrl` / `Alt` / `Meta` 的普通键才算设置成功；只按修饰键只显示提示、不保存。

## 2. 静音自动停

开始录音后插件自己开一路麦克风做能量分析：确认听到说话后，若连续静音达到设定时长，就替你点官方那个「停止并识别」。

**两个入口都管**：热键开录，或者你用鼠标点官方那个麦克风开录。判定用的是官方写在 DOM 上的相位属性 `data-voice-activity`（`requesting / recording / transcribing / feedback`，idle 时整行消失）。插件用 `MutationObserver` 盯着它（50 ms 合并一次，避免跟着流式输出的 DOM 变动跑）：

- 相位变成 `recording` → 开静音分析；
- 相位回到 `idle` → 这一轮结束：把光标送回输入框末尾，按设置决定是否自动发送。

所以鼠标开录不会再「绕开插件」。

设置项：

- **说完自动结束录音**：关掉退回纯手动模式（自己再按一次热键，或按空格）。
- **停顿多久算说完**：`0.5–10 秒` 滑块，步进 250 ms，默认 2 秒。

阈值自适应环境底噪（双门限 + 迟滞），因此：

- 按下热键后**先静半秒再开口**，底噪校准更准；
- 环境噪声很大时可能判不出静音，此时用「长按说话、松手停」更可靠。

## 3. 聚焦输入框（默认 `Ctrl+Alt+I`，可改）

默认值对齐主流：Cursor 用 `Ctrl+L`（浏览器里被地址栏抢走）、VS Code 的 GitHub Copilot Chat 用 `Ctrl+Alt+I`、Claude Code 用 `Ctrl+Esc`（Windows 上是开始菜单）。只有 `Ctrl+Alt+I` 在网页版与桌面版上都安全。

DSH 没有任何「把焦点送回输入框」的快捷键。官方语音插件靠开录瞬间的光标位置决定插入点，一旦光标丢了（点了侧边栏、切了窗口），转写结果就无处可落。

这个热键做一件事：找到 `[data-composer-input] [contenteditable="true"]`，`focus()` 之后把 Range 折叠到内容末尾。若当前焦点本就在可编辑元素里则不抢。

它独立于录音，任何时候按都有效 —— 配合语音热键就是完整的键盘流程：`Ctrl+Alt+I` 回框 → `Alt+V` 说话 → 自动停 → `Enter` 发送。

## 4. 说完自动发送（默认关）

打开后，转写完成、光标回到输入框的那一刻，插件替你按下发送。

- 判据是官方的相位属性从 `recording` / `feedback` 回到 `idle`，**不是**「停止录音」的瞬间 —— 停止后转写还要几百毫秒。
- 触发条件收紧成「同一个输入框、比开录前多了字」：手动取消、转写失败、中途切了会话都不会误发。
- 之后等 180 ms 再确认文字有没有落进来（转写写回是异步的），没落就每 200 ms 重试，最多约 1.4 秒，仍没有就放弃。
- 发送优先点官方的「发送消息」按钮（`aria-label` 取自语言包键 `input.send`）；找不到按钮（例如正在生成、按钮变成「停止生成」）才退回合成一次回车。
- 它发的是**输入框里的全部内容**，包括你原本手打的字。想先校对就别开，或者发完关掉。
- 中途关掉开关、或开始下一次录音，待发的定时器会立即作废。

## 5. 录音时那行的三个动作：取消 / 停止 / 转完就发

官方录音行只有 `X · 波形 · 停止并识别`，发送箭头在整行最右边。本插件不新增按钮，而是把这三个动作摆成一个紧凑的右侧组：

- **X**：取消这一轮，什么都不发（官方行为）。
- **✓**：停止录音并开始转写（官方「停止并识别」，图标换成细勾，跟 X、发送箭头同一套线条）。
- **发送箭头**：直接复用官方那个蓝色发送按钮，不额外插一个纸飞机。录音或转写中点它就等于「不用看文字，转完直接发」：
  - 还在录 → 立刻停止、转写，文字落地后自动发送；
  - 已在转写 → 只设标记，等文字落地再发；
  - 再点一次 → 取消设定。

点下去后行里会出现 `转完即发` 小提示（点它也能取消），同时发送箭头描一圈高亮。实现上不动官方录音链路：只是接管发送箭头的点击（把「这一轮转完就发」的标记立起来，再派发点击官方「停止并识别」），真正的发送仍走第 4 节同一套收尾 —— 同一个输入框、确实比开录前多了字才发，所以中途点 X、转写失败、切会话都不会误发。非录音/转写阶段完全不拦截，正常发送不受影响。

行内布局用 CSS 重排：波形占左边，`X / ✓ / 发送箭头` 聚在右边（官方原本把 X 放在最左，离另外两个太远）。提示的补挂靠 `MutationObserver` 盯 `[data-voice-activity]`，React 重渲染冲掉会自动补回。

官方这行本身没有红点和时长，插件在同一行补了两样：波形左边的呼吸绿点（跟随记录状态的主题绿）、右边的 `0:07` 计时（转写时停住）。状态字（「正在聆听…」）试过、会多占一行把按钮挤下去，所以不放。X 和 ✓ 按钮 34px、图标 18px（跟官方发送按钮同尺寸），同一套自绘线条（1.6 描边、同一灰色），不再一个 14px 描边图标配一个 16px 勾。

## 6. 切换语音识别服务（麦克风左边的小下拉）

输入框工具条右侧、模型选择器右边（紧挨麦克风）多一个小下拉，列出官方 `speechToText` 服务当前注册的所有识别器 —— 装了什么就有什么，例如「豆包 / 豆包·顺稿 / 本地」。选一下就切，下一次录音立即按新服务转写，不用重启、不用改配置文件。

- 读：`ctx.remote.speech.catalog()`，拿 `providers` 与 `selection`。
- 写：`ctx.remote.speech.configure({ providerId })`。它由官方 Host 侧写进 `speech-to-text` 条目的 `defaultProvider`（该字段声明为 volatile），Host 收到 `loader/volatile-update` 后就地更新，转写时 `resolve()` 每次现读配置。
- 所以选择是持久化的：写进 profile 的 `cordis.patch.yml`，下次启动还是这个。

实现上不碰任何转写代码：豆包插件继续做 provider，本插件只做控制面。切换失败会重新拉一次 catalog 把下拉拨回真实值，不会假装切成功。

下拉里的文字从哪来：

- 选项列表是 `catalog().providers`，每个 provider 的 `id / name / location / languages` 都由插件自己注册时上报，**不是写死的**。
- `豆包 / 豆包·顺稿` 是本插件对 `doubao`、`doubao-polished` 两个 id 的中英短名映射（英文界面用 Doubao），其它 id 直接显示 `info.name`。
- 后缀「云端 / 本地」来自 `info.location`（`cloud` / `host-local`）。
- 模型档位：本地 SenseVoice 的 INT8/FP32 就在 `info.name` 里（`SenseVoiceSmall (INT8)`），所以能看到；豆包的 2.0/1.0 档由插件配置里的 `resourceId` 决定，`catalog` 不暴露，所以下拉里看不到，只能算在「云端」名下。
- 鼠标悬停能看到 `info.name` 加支持的语言列表。

没装豆包插件时：列表里只有本地 SenseVoice，不报错。装了豆包但没配 Key 时：provider 仍会注册，选了转写会失败（错误来自豆包插件）。官方 `speech-to-text` 没挂载时：显示灰色「语音服务」占位；服务在但一个识别器都没注册时：显示「无可用识别服务」。

限制：`speech/*` 在官方 LiveShare 里是 `owner-only`，分享出去的会话里这个下拉会读不到列表（此时整块不渲染）。切的时候正在录音不影响，新服务从下一轮开始生效。

## 设置存放

浏览器 `localStorage` 键 `dsh-voice-hotkey:settings`，改完立即生效，不需要重启。清站点数据会回到默认。

桌面版（Electron）里 `localStorage` 可能被 `file://` 或分区策略拦住，此时自动退化为内存存储：当次会话有效，不清空、不抛错。

## 边界

- 依赖官方 `dsh-experimental-client-ui-voice-input` 渲染的按钮（`aria-label` 为「开始录音 / 停止并识别 / 重新录音」，相位属性 `data-voice-activity`）；它没启用时热键不会有反应（控制台会有一次 `[voice-hotkey]` 警告）。
- 转写仍走官方链路（默认本地 SenseVoice；装了我们 fork 的豆包插件就能在这里切云端），本插件不改变识别质量。
- 静音判定只看音量，不看语义；说话中间停顿超过设定时长会被判为说完了。
- 不支持「边说边出字」：官方识别是一次性返回的。
- 主题样式用 DSH 的设计令牌（`--dsw-alias-*`），每个值都带 fallback，深浅色都跟随系统。
- 桌面版是 Electron 壳套同一份 Web 界面，插件在渲染进程里运行，无需额外权限；麦克风权限由桌面应用授予。
